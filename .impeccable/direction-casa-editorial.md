# Casa editorial · dirección aprobada para implementación local

Autorización de Aldo: «Adelante, vamos a realizarlo a partir del plan y las imagenes oficiales, si consideras necesario incluir alguna mejora durante el proceso no lo dudes.»

- **THESIS:** la librería se descubre como una casa real; una entrada cinematográfica breve conduce a fotografía documental, lectura calmada y visita/conversación.
- **OWN-WORLD:** piedra, madera, piso ajedrezado, turquesa y mesas compartidas de las seis fotos oficiales. Playfair Display + Inter y la paleta verde/tinta/menta/papel/ámbar existentes. Sin marcas, claims, fotos o bundles de Miu Miu/Noho.
- **STORY:** Inicio → Experiencia → Agenda → Galería → Visita. Solo el ingreso conserva el escenario audiovisual. Experiencia/Galería usan papel para recuperar claridad; Agenda verde; Visita tinta sin video.
- **FIRST VIEWPORT:** datos prácticos antes del título; titular actual y dos acciones; fotografía de la sala en encuadre contenido, dentro de su resolución. Móvil conserva horario y CTA, con medios opcionales y menú accesible.
- **FORM:** HTML estático, CSS local, JS nativo. Cinco section y anchors actuales. Los originales se preservan, los derivados se codifican sin ampliación. El catálogo/Iti IA siguen pausados. Sin deploy, commit, cambios de credenciales o generación de un nuevo mundo 3D.

Fuente de composición: `web-intel/awwwards-libreria/2026-10-27/PLAN.md`. La aprobación permite pasar directamente a Casa editorial; no requiere otra elección de paleta ni más renders para demostrar el concepto. Los documentos visuales se actualizan a la implementación revisada; las decisiones anteriores incompatibles con esta composición quedan sustituidas, no los límites de producto, seguridad o procedencia.
